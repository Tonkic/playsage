## 实测发现与边界

游戏为管理员进程，后端匹配权限后完成输入；管理员提示由用户手动确认。菜单动画会导致图块检查停止，增加了唯一且稳定的原生 OCR 标签定位。第一关高亮采样曾误判并停止，依据真实截图调整到外边框后继续；通信或状态未知不自动重发按键。

第二关首次保守避开三个普通格，活动包用 excluded 记录，与真正 X 障碍分开。旋转棋盘的可达性剪枝采用乐观上界以免误剪有效解，实际 DFS 每一步仍校验方向，搜索有节点上限。

这次由 Agent 观察、建模和确认结果，未实现自动棋盘提取、通用 CLI 实机 replay 或 verified 晋升。重进选择页第一案显示“已完成”，点击未出现回放入口；没有完整重放验证。其余四案和其他三个游戏未验证。通用单步工具的场景检查仅覆盖原生精确识别结果，未知页面仍依赖 Agent 目视检查。

游戏停留在活动选择页，没有单关执行器继续运行。OneDragon 后端在本机 127.0.0.1:23001 待命；服务信息位于 runs/services/onedragon/service.json。
